# ComplexMatrixCalculator

Практическая работа №1 по Java.

Консольная программа для выполнения операций над матрицами комплексных чисел.

## Возможности

- Сложение матриц
- Умножение матриц
- Деление матриц (при существовании обратной матрицы)
- Транспонирование
- Вычисление определителя

## Структура проекта

- `ComplexNumber.java` — класс комплексного числа, арифметические операции.
- `ComplexMatrix.java` — класс матрицы и реализация операций над матрицами.
- `Main.java` — консольное меню и ввод данных.

## Запуск

1. Открыть проект в IntelliJ IDEA.
2. Запустить метод `main()` в файле `Main.java`.
3. Выбрать операцию в консольном меню.
4. Ввести размеры матрицы и её элементы.

Каждый элемент вводится двумя числами через пробел: действительная и мнимая части.

Например, `3 2` соответствует числу `3 + 2i`.

## Особенности реализации

Для вычисления определителя используется метод Гаусса. Обратная матрица находится методом Гаусса — Жордана.

При выполнении операций проверяется совместимость размеров матриц. Деление возможно только на обратимую квадратную матрицу.
